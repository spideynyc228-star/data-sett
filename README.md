# KROK Hackathon — Prompt Radar Dataset

Синтетический русскоязычный датасет для хакатона КРОК по анализу запросов к ИИ-агентам.

## Содержимое

- `dataset/dialogs/` — 100 диалогов пользователя с агентом и вызовами инструментов;
- `dataset/generate_dataset.py` — генератор набора;
- `dataset/manifest.json` — манифест файлов и их метаданные.

Диалоги полностью синтетические: они не содержат реальных персональных, корпоративных или клиентских данных. В наборе есть рабочие и нерабочие сценарии, а также примеры исправления ошибок агентом.
